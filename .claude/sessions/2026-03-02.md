# 2026-03-02 Session Log

## Fix ATT (App Tracking Transparency) Review Rejection - Guideline 2.1

**Issue**: App Store rejected v1.0.3 because `NSUserTrackingUsageDescription` + SKAdNetwork IDs were declared in Info.plist, but no ATT dialog ever appeared.

**Approach chosen**: Remove tracking declarations entirely (no ATT prompt needed). The app doesn't need IDFA — TikTok attribution still works via server-side events.

**Changes**:
- `ios/Runner/Info.plist`: Removed `NSUserTrackingUsageDescription` and `SKAdNetworkItems` (3 network IDs)
- `lib/services/analytics/tiktok/tiktok_service.dart`: Set `disableTracking: true`, `disableAutomaticTracking: true`, `disableAdvertiserIDCollection: true` — no IDFA collection
- No new dependencies needed

**Manual step required**: In App Store Connect → App Privacy, update to declare the app does **not** track users. Then rebuild and resubmit.
