
## PostHog analytics coverage expansion

Added meaningful PostHog events to user-facing flows that had zero tracking, following the existing `_analytics.isReady + events.trackCustom` pattern. Skipped dead boilerplate (verse_library, progress/home mock controllers) and did not duplicate onboarding/paywall module coverage.

Files & events:
- cozy_mood_check_in_screen: mood_check_in_submitted (mood, moment)
- cozy_streak_intro_screen: streak_intro_viewed (streak)
- grace_garden_screen: garden_viewed, garden_onboarding_completed, garden_replayed, garden_journal_opened
- prayer_library_screen: prayer_library_viewed, prayer_library_prayer_selected (prayer_id, domain, source)
- paywall_controller: subscription_restore_started / _no_purchases / _failed
- faithlock_settings_controller: settings_lock_toggled, settings_notification_permission_result
- profile settings_controller: language_changed (language, previous)
- cozy_reflections_screen: reflections_bookmark_opened (reference)
