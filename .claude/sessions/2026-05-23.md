## Onboarding V3 — fix overflow première page (V3WelcomeCarousel)
- **Quoi**: `_SlideView` (lib/features/onboarding/screens/v3/v3_welcome_carousel.dart) débordait de 43px en bas. La Column (mascotte XL 200px + padding + titre + corps long) était dans un `Expanded` à hauteur bornée par le `PageView`, non scrollable → overflow sur la slide 1 (texte le plus long), pire sur petits écrans.
- **Fix**: pattern `LayoutBuilder` + `SingleChildScrollView` + `ConstrainedBox(minHeight: maxHeight)` + `IntrinsicHeight` → centré quand ça rentre, scrollable sinon. `space40` → `space32` pour resserrer.
- **Pourquoi ce choix**: robuste sur tous les appareils sans casser le design centré, plutôt que du pixel-tuning device-spécifique.
