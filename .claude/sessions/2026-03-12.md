# 2026-03-12

## Make age optional in onboarding (Apple Guideline 5.1.1)

**What**: Age field in onboarding made optional with Skip button. LifeVisualization widget gains preview mode (blurred + CTA overlay at age 30 default). Settings screen gets new "Personal" section for adding/editing age post-onboarding. Age no longer sent to analytics.

**Files modified**:
- `lib/features/onboarding/controllers/scripture_onboarding_controller.dart` — Added `ageSkipped` state, `skipAge()` method, removed age from analytics
- `lib/features/onboarding/controllers/scripture_onboarding_v2_controller.dart` — Removed age from analytics metadata
- `lib/features/onboarding/screens/step1_5_name_capture.dart` — Added Skip button below Continue on age picker
- `lib/features/onboarding/widgets/life_visualization.dart` — Added `isPreview` + `onPreviewTap` params, preview overlay with blur+CTA
- `lib/features/onboarding/screens/step2_self_confrontation.dart` — Passes `isPreview` based on `ageSkipped`
- `lib/features/onboarding/screens/v2_self_confrontation.dart` — Same
- `lib/features/faithlock/controllers/faithlock_settings_controller.dart` — Added `loadUserAge()`, `saveUserAge()`, `showAgePicker()` methods
- `lib/features/faithlock/screens/settings_screen.dart` — Added "Personal" section with age tile
- All 5 locale files (en_US, fr_FR, de_DE, ja_JP, pt_BR) — Added `lifeViz_previewCta`, `lifeViz_previewAction`, `settings_personal`, `settings_age`, `settings_ageNotSet`, `settings_ageValue`

**Key decisions**: Age stored locally only (SecureStorage), never sent to server/analytics. Preview uses age 30 as default with ImageFilter.blur + 35% opacity.
