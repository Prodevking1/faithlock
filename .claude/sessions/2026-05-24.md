**What**: `scripts/prayer_pipeline/generate.mjs` `audio` phase switched from the ElevenLabs direct API to
Replicate's `elevenlabs/v3` model (voice "Paul"), POST + `Prefer: wait` with a polling fallback for long

`.env` only. ⚠️ Secret key was shared in chat → user should rotate it.
