## Fix: gray-screen crash after "Building your honest reflection" loader (V3 onboarding)

- **What**: V3 reveal screen (`v3_reveal_screen.dart`, rendered right after `V3FakeLoader`) crashed with `type 'Null' is not a subtype of type 'int' in type cast`. Root cause: `calculateRevealStats()` (`scripture_onboarding_v3_controller.dart`) never returned a `lifetimeHours` key, but the screen did `stats['lifetimeHours'] as int` → `null as int` → throw every build frame → gray screen.
- **Fix**: Added `lifetimeHours = (hours * 365 * yearsRemaining).floor()` to the returned map. Also hardened the screen's two reads to `(stats[...] as num?)?.toInt() ?? 0` so a missing/mistyped key can never hard-crash the flow again.
- **Notes**: This is the early reveal sequence (case 11→12), not the late `V3BuildingPlanLoader`→paywall path. flutter analyze clean on both files.
