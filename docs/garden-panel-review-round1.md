## Strongest convergences — ADOPT (multiple experts agree independently)

1. **Prayer must stop farming Faithfulness → make it garden-wide "rain" (splash only, no single-fruit award).**
   - 🎮 flags the *exploit*: +4 GP/min uncapped → idle-prayer farm → Faithfulness monoculture → breaks "the garden tells your story."
   - ✝️ flags the *theology*: prayer is communion, not a faithfulness score ("pray more = more faithful" is false). Make it a gentle rain God sends over the whole garden.
   - → Same fix from two directions. **Highest-priority structural change.**

2. **Reframe all language: "you tend / God grows" — never "you grew / earned." Demote raw scores; turn "harvest" outward.**
   - ✝️: the verbs/numbers quietly teach works-righteousness/synergism (1 Cor 3:6-7, John 15:5). The bar = "time abiding," not "holiness."
   - ✍️: the grace mechanic (growth never lost) is the product's *soul*; the copy must make it land, not undercut it.

3. **Let the user perform a tending gesture (harvest fruit, prune/clear leaves) — not just passive counters.**
   - 🌿 (most "alive"-making interaction), ✝️ ("you tend, God grows" embodied), ✍️ (rituals). Triple convergence.

4. **Joy = Sunflower is the one botanical contradiction** (annual → dies yearly → can't age endlessly). Swap to a flowering plum / citrus (keeps bright-gold cheer, true perennial), or keep sunflower as a self-seeding patch exempt from tree-aging. (🌿)

5. **The Companion becomes a named character: "Pip"** — a small, humble helper-gardener; warm, never preachy, deflects glory to God. (✍️ delivers full character bible + paste-ready copy; ✝️ supplies the voice guardrails.)

6. **Evergreens stay green in winter** (pine/olive) while deciduous sleep → *Faithfulness stays green when all else rests* = strong theological payoff + real botany. (🌿 + ✝️ winter-rest/Sabbath framing.)

7. **Asset prompts need a full overhaul** (🎨): tool-tuned style prefix (tri-count, watertight, separate foliage material, no baked camera/shadows), endless aging via additive meshes + a `grove` state, **wilt = in-engine shader on a dedicated foliage material** (no baked wilt models), mascot via locked turnaround → image-to-3D → T-pose rig, and prompts/recipes for every missing piece (watering/grow/bloom/harvest/revival VFX, golden-hour + day/night lighting, dew, pollinators, empty/planted plots, locked/unlock decor, trophy shelf, companion sapling, journal UI icons). .glb vs PNG-sprite vs SVG cleanly separated.

## Other notable Round-1 recommendations (for the v2 synthesis)

**🎮 Game designer (balance):** cap prayer GP/day (~+20); per-fruit daily GP cap (~40 pre-multiplier) to smooth the curve without a total cap; cap splash (~+10/plot/day) to stop year-1 homogenization; soften first post-Fruit tier (Young tree ~160 not 260); pin **harvest cadence to bi-weekly in-app seasons (~26/yr)** decoupled from visual calendar seasons; comeback +12 (≤ active) to kill skip-to-gain; surface a "thriving ☀️" health state (not only wilt); add a weekly Sunday recap; add surprise-and-delight (behavior-caused, never random); gentle "garden portrait" image export.

**✍️ Narrative:** stage names → verbs (Seed → Sprouting → Growing → Blossoming → Bearing fruit); journal gets a one-line Pip header per plot that reflects real data as story; **Seasonal Letters from Pip** (4×/yr); rotating ambient verse themed to the user's strongest-growing fruit; **memory stone** honoring a hard-season comeback; optional "share the harvest"; a covenant first-line for new users ("I can't make anything grow — that's not my job, or yours. We just show up and water.").

**✝️ Pastor (guardrails):** rename resource to "care/time tended"; always-visible "You tend; God gives the growth"; reframe wilt as "resting/waiting," + suffering-safe note ("a bare plot is never His disappointment," Ps 34:18); fix attribution copy → "Time with God on [theme] — He often grows [fruit] here"; pride→Kindness is a stretch (map to Gentleness or splash); Pip never praises performance / never speaks as God; scripture always with reference + context, never confetti/loot; one quiet "this is a picture, not a scoreboard" anchor screen.

**🌿 Gardener (realism):** differentiate the 3 green canopies (oak = broad spreading dome, apple = short low-branching orchard form + baked red fruit, pine = triangular) by silhouette not props; give Patience/Oak the steepest endless curve + largest ancient (slow + enduring); **stagger blooms by real seasonal timing** (cherry early spring, rose/olive summer, apple blossom→fruit, grape late summer) so the garden is never uniformly "done"; transient micro-events (dew that evaporates, drifting petals, a bee that lands then leaves, one falling leaf); companion sapling as visible legacy/regrowth.
