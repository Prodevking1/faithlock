# Règles de rédaction SEO FaithLock — index

Système repris de Montaj (`montaj/website/seo/`), adapté à FaithLock. Ordre de lecture pour rédiger une page :

1. **`CONTENT_WRITING_RULES.md`** — le process + le système de cohérence des données (prévenir avec les fichiers de faits, détecter avec l'agent fact-check). Inclut les règles de style (⛔ tirets « — », zéro claim inventé).
2. **`CONTENT_FORMAT_RULES.md`** — l'anatomie, les mots-clés, les ingrédients et la scorecard (Definition of Done ≥ 80/100) de chacun des 7 formats FaithLock.
3. **`FAITHLOCK_FACTS.md`** — source de vérité A : les faits produit. ⚠️ à valider par le fondateur.
4. **`COMPETITOR_FACTS.md`** — source de vérité B : les faits concurrents. ⚠️ à remplir avec sources datées.
5. **`reference-montaj/`** — les originaux Montaj (lecture seule, pour traçabilité).

## Workflow (résumé)
Pour chaque page : brief (format, mot-clé, sous-mots-clés, killer element, slug) → fiche du format → faits depuis les 2 fichiers FACTS (jamais inventer) → rédiger (keyword-slots, FAQ verbatim des requêtes GSC, CTA, maillage ≥ 3) → auto-scorecard ≥ 80 → agent fact-check (0 flag) → prêt pour import Contentful.

## Avant d'industrialiser
Pilote de 10 pages étalon couvrant les formats du lot → validation qualité → puis batch.
